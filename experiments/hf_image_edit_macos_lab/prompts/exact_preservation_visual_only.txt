This is an exact preservation visual-consistency test.

Recreate the reference image as faithfully as possible while preserving its
visual structure and photographic feel.

Hard constraints:
- Keep the same camera position.
- Keep the same camera height.
- Keep the same perspective and lens feel.
- Keep the same framing and crop.
- Keep the same viewing direction.
- Keep the same scene geometry and large-scale composition.
- Keep the same relative spatial arrangement visible in the image.
- Keep the same depth layering and foreground/background balance.
- Keep the same color temperature and overall palette character.
- Keep the same brightness range and contrast feel.
- Keep the same soft natural-light mood if present.
- Keep the same shadow direction and shadow softness.
- Keep the same highlight behavior and exposure balance.
- Keep the same calm minimalist visual tone.
- Do not redesign the image.
- Do not shift to a different room or scene interpretation.
- Do not introduce a new composition.
- Do not crop tighter or wider.
- Do not rotate or reframe the viewpoint.

Allowed changes:
- Slightly improve realism.
- Slightly improve texture fidelity.
- Slightly improve local detail while preserving the same visual appearance.

Output goal:
The result should feel like the same image re-rendered with higher fidelity,
not a new design inspired by it.
