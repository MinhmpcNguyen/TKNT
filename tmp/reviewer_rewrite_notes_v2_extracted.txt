[369] Suggested rewrite:
[370] Future work can improve the system in four directions. First, the layout solver can be extended to more room types and richer constraints, such as kitchens, bathrooms, multi-room apartments, electrical outlets, and furniture-opening interactions. Second, the image workflow can be improved by using stronger structural controls, more reliable masks, and automatic detection of layout drift. Third, image-only edits can be synchronized back into the editable 2D/3D layout when the edit corresponds to a concrete object change. Fourth, the evaluation can be expanded with larger benchmarks, user studies, and comparisons against professional or semi-professional design workflows. These extensions would move the prototype from early-stage assistance toward a more complete design support tool.

[375] Suggested rewrite:
[376] The main lesson from this thesis is that AI-assisted interior design should not be treated as pure image generation. A useful system must keep a controllable representation of the room, furniture, openings, and user intent throughout the workflow. Generative models can provide semantic interpretation and visual realism, but they become more reliable when they are connected to deterministic geometry, editable state, and explicit evaluation. This hybrid view is the basis for the proposed TKNT system and for future extensions of the work.
