RoomFlow – AI-Powered Interior Design

Interactive Generative AI for Constraint-Aware Interior Layout and Photorealistic Synthesis

Overview

RoomFlow is an end-to-end AI-powered interior design system that transforms natural language requirements and room geometry into spatially feasible furniture layouts and photorealistic interior designs.

Unlike conventional image-based generative design approaches, RoomFlow combines LLM-based multi-agent reasoning with deterministic geometric constraint solving, bridging the gap between visual creativity and practical spatial feasibility.

The system was developed as my graduation thesis at Hanoi University of Science and Technology (HUST).

Key Features

* Natural Language Understanding: Extracts design requirements, preferences, and functional needs from user input.
* Multi-Agent Architecture: Coordinates specialized AI agents across different stages of interior design.
* Constraint-Aware Layout Generation: Incorporates geometric and spatial constraints into furniture placement.
* Automated Layout Verification: Evaluates generated layouts against predefined constraints.
* Interactive Room Editor: Supports room geometry modification, wall creation, and drag-and-drop furniture interaction.
* Photorealistic Synthesis: Transforms generated layouts into realistic interior design visualizations.
* Human-in-the-Loop Design: Allows users to review, select, and refine generated designs.

System Architecture

The system integrates three complementary approaches:

* Semantic Intelligence: LLM-based reasoning, requirement extraction, task decomposition, and agent coordination.
* Spatial Intelligence: Furniture grouping, geometric reasoning, constraint solving, placement, and verification.
* Visual Intelligence: Generative AI, interior styling, and photorealistic synthesis.

End-to-End Workflow

1. User requirements and room geometry
2. Requirement understanding and task decomposition
3. Furniture selection and grouping
4. Constraint-aware layout generation
5. Layout verification
6. Interactive user selection and refinement
7. Photorealistic interior synthesis
